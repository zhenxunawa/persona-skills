## 技能里写成了什么

- 长度配额：每 20 条按 1-3 / 4-6 / 7-15 / 16-30 / 31+ 字分配条数，不靠感觉写长短
- 口头禅带次数：高频词按真实出现频率给，不是列一张清单
- 场景分层：默认接话、被 @ 时、深夜、讲技术/讲题、求助，各写一套
- 第三轮脏度配额：纯符号几条、半截话几条、拆句几处，防止写得比真人还干净或还夸张
- 自检清单：生成前逐条对照，生成后回读长度分布

## 用法

```
/wind            # 用这个人的口吻说话
```

也可以在对话里直接点名：「用 Wind 的语气回一句」。

## 已知局限

- 未单独做盲判。同类技能的换算基准：50% 表示分不出真人与生成。
- 语料来自 QQ 群导出，转发内容约占 2%-4%，已尽量剔除但不保证干净。
- 只用于文字语气，不模拟语音、不模拟他的知识量与经历。
